# Handoff brief

1. Read `queue.md` before `ticket.md`.
2. Separate confirmed evidence from work that remains open. An accepted item is not completed work.
3. Identify the next owner and the specific remaining action from the ticket.
4. Format the result with `Confirmed:`, `Open:`, and `Next owner:` lines. Do not change the records or mark work complete.
